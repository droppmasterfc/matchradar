# MatchRadar

Plataforma de inteligência esportiva que monitora tendências em tempo real e transforma oportunidades de mercado em campanhas e criativos gerados por IA.

## MVP

- Captura de tendências esportivas
- Jogos do dia
- Hype Score
- Geração de copies com IA

## Stack

### Frontend
- Next.js
- Tailwind

### Backend
- FastAPI

### Banco
- PostgreSQL

### IA
- OpenAI API
